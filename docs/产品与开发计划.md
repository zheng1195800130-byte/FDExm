# FDE Desk 第一版

## 已确认的使用方式

单人 Windows 本地应用，完整工作台和可拖动、置顶的悬浮球。日常开发始终在 Codex 桌面端同一个聊天中进行。客户沟通以飞书为主，会议提供文字纪要文件；资料允许 AI 分析。本工具不自动发消息。

用户事先准备两个目录：原始资料目录、项目开发目录。前者只读关联，后者只读关注文档成果；管理数据另存。本轮不操作已有客户项目，不把其他项目当作示例。

## 四个核心能力

1. 资料：索引原始资料、收录后续补充资料、简要用途介绍、按名称/介绍/可提取正文搜索、预览、复制文件和路径。补充资料按上海日期复制归档，原件不移动。
2. 需求：简洁需求清单，区分待确认、已明确、已变更、已完成，关联原始证据和当前周期。Codex 已生成的分析/方案/流程图只引用。
3. 工作：记录事项、原因（适用时）、处理、结果、状态和来源。相同事项同一天合并，多轮持续更新；保留跨天历史。日报只使用已确认有效记录，简明适合非技术读者。支持编辑和导出 Markdown。
4. 进度：阶段、最近有效成果、剩余事项、阻塞、下一步、交付版本。状态由明确记录或人工确认，不能用文件修改推定测试通过或客户验收。

## 组织规则

一个项目一份档案，一轮需求到客户满意为一个周期。首次交付周期包含需求、自测、多次交付和客户反馈修复，可持续多天。日期组织补充资料、工作和日报；事项编号关联跨天工作。项目资料保持独立于开发仓库。

## 第一版实现

采用 Electron + HTML/CSS/JavaScript，无本地 HTTP 服务，无在线依赖、无 API key 要求。管理数据以原子 JSON 保存并输出可读 Markdown，备份和错误恢复。Office/PDF 常用文本解析；图片/音视频保留原件路径和可编辑描述，第一版不自带 OCR/转写。

工作台：项目概览、资料库、需求清单、工作记录、日报、Codex 收录。悬浮球展开资料检索面板、项目切换和复制路径，快捷键 Ctrl+Shift+Space。提供原生文件/目录选择、拖入/粘贴收录、文件复制。

Codex：验证本机已有会话读取。仅用户主动关联的会话可读取，过滤工具输出/思考/长代码；候选消息在内存供人工收录，FDE 不复制完整对话。保留粘贴收录入口。只读兼容适配不控制 Codex、不自动提交任务；明确显示兼容性/读取错误。

## 验收

- 新建项目可关联两个真实目录，原始文件哈希不变；重启后数据存在。
- 多种资料可索引预览；补充资料按日期安全归档、文件冲突不覆盖。
- 多轮同事项合并，跨天不覆盖，未确认内容不写入已完成日报。
- 悬浮球可展开、拖动、置顶，文件/路径可复制，工作台可恢复。
- Codex 会话有匹配路径和显式关联；仅有效摘要人工确认入库。
- 使用临时样例做端到端验证，不导入客户资料到演示项目。

## 后续

真实使用后再决定自动摘要模型、OCR、客户测试跟进提醒、飞书连接和安装器自动更新。本轮交付可运行的本地应用与便携版本。
