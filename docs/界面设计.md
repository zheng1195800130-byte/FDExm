# 界面设计

使用 UI/UX Pro Max 查询结果中适配桌面生产力工具的 Flat Design 与渐进披露指导。其营销页面布局和展示字体不适用于本工作台，未采用。桌面布局由本产品需求确定。

采用米白背景、深蓝灰文字、青绿色主操作，少量橙色标示待确认。侧边栏固定项目和导航，中心内容可滚动，右侧概览上下文。系统中文字体，不加载外部字体。16px 正文，14px 辅助内容，明确键盘焦点、图标标签和状态文字。圆角 10-16px；仅浮层有柔和阴影。

空数据呈现真实引导，不填充虚假项目或百分比。所有表单有标签和错误提示；保存有反馈，异步操作禁用重复提交。悬浮模式通过「资料」「备忘录」两个页签切换，不挤入完整管理界面。

备忘录沿用当前项目选择，文字输入区保持固定 DOM，后台广播不重置光标或选区。显示自动保存、保存失败和重试状态；图片按可见区域加载预览，保留宽高比例。截图粘贴、复制图片与打开目录均有明确文字按钮，键盘可操作。
